# Contributing to Caimack

Bug reports, documentation improvements and code contributions are welcome.

## Prepare a pull request

1. Follow the [development setup](docs/development.md) if you need to run Caimack.
2. Run the [checks](docs/development.md#run-checks) for the parts you changed.
   Update the relevant [guide](docs/README.md) when a command, setting, or user
   workflow changes.
3. Keep the diff focused. Describe what changed and how you verified it in the
   pull request.
